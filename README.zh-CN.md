# doc2kb：文档转 Markdown 知识库

**把一整个文件夹的办公文档交给它，得到 AI 助手真正检索得了的 Markdown**：合并成一个带索引的文件，或每份文档一个文件。

- **零依赖**：只用 Python 3.7+ 标准库，不需要 pandoc、LibreOffice、python-docx、openpyxl、python-pptx，拷到离线机器上就能用。
- **该留的都留着**：标题层级、表格、嵌入的 Excel 附件和每张图片的位置都保留。
- **重复只收一份**：内容相同的文件（包括 zip、tar 压缩包里的）只解析一次，目录挪动或改名后也不会重复入库。
- **装好就不用管**：增量模式配合 cron，每次只处理上次之后有变化的文件。
- **多种用法**：可以在浏览器里用（双击启动），也可以用命令行运行，还可以把 `doc2kb_core.py` 当库导入。

支持 `.docx` `.xlsx` `.xlsm` `.pptx` `.pdf` `.eml`、旧版 `.doc` `.xls` `.ppt` 和压缩包，提示信息和输出里的标签可选中文或英文。

## 目录内容

| 文件 | 说明 |
| --- | --- |
| `doc2kb_core.py` | 转换器：文档解析、内容抽取、图片导出、产物写出。命令行参数控制全部行为，不含界面代码。 |
| `doc2kb.sh` | 入口脚本：不带参数启动网页界面；带参数进入命令行增量模式，可放进 crontab |
| `doc2kb_web.py`、`doc2kb.html` | 网页界面：本机网页服务（只监听 127.0.0.1）及其页面，提供目录批量、指定文件、增量任务、清理重复 |
| `双击运行.desktop` | 网页界面的桌面启动入口 |
| `doc2kb_dedup.py` | 目录移动或改名后，删除合并 / 增量文件中正文已在其他产物里出现过的文档节 |
| `SPEC.md` | 行为契约（英文）：输入、产出与边界处理，供重新实现或理解设计取舍 |

## 运行环境

- Python 3.7 及以上，只用标准库。
- 以下外部命令为可选，缺失时对应功能给出提示并跳过：
  - `pdftotext` / `pdfimages` / `pdfinfo`（poppler-utils）：处理 PDF
  - `montage`（ImageMagick）：仅「合并拼图」需要
  - 浏览器：仅网页界面需要
- 必须用 bash 运行 `doc2kb.sh`，不能用 sh。

从 [Releases](../../releases) 下载 `doc2kb-<版本>.zip`，或克隆本仓库。

## 语言

提示信息和写进产物的标签（标题、说明、表头）有中文和英文两种。`doc2kb.sh` 按环境变量 `DOC2KB_LANG`（en 或 zh）选择，未设置时看系统 locale，`zh` 开头即中文。`doc2kb_core.py` 用 `--lang en|zh` 指定（默认取 `DOC2KB_LANG`，否则英文）。中文产物的标签与文件名在各版本间保持不变，已有的输出目录和正文指纹库可以继续使用。

## 使用方法

### 网页界面

双击 `双击运行.desktop`，或不带参数运行 `./doc2kb.sh`（也可运行 `python3 doc2kb_web.py`），浏览器中打开页面，分四个标签页：

- **目录批量**：选择源目录（输入路径或点「浏览……」），需要时勾选日期过滤，点「扫描」；取消勾选不想处理的文件；确认输出目录（默认 `源目录/_知识库`）和选项，点「开始」。结果区显示汇总与报告，「打开输出目录」打开产物所在目录。
- **指定文件**：从一个或多个目录添加文档或压缩包后开始；指定的文件每次都重新转换（替换同名 md 前先确认）。
- **增量任务**：新增、编辑、删除任务（任务名、源目录、输出目录），预览、执行勾选的任务或全部执行。从未运行过的任务处理最近 N 天内修改的文档（默认 30，可在页面上改）。任务保存在 `~/.config/doc2kb/watch_tasks.conf`，与早先版本是同一个文件。
- **清理重复**：选择合并或增量 md，先试运行并核对报告，再清理（原文件先备份）。

`.msg` 文件会列出并跳过。

不勾选「导出图片」时不导出图片。服务只监听 127.0.0.1，网址带一次性令牌；页面全部关闭几秒后自动退出，点「退出」立即结束；有任务运行时等任务结束再退出。路径在服务提供的目录列表里选择，而不是用浏览器的选文件框，因为转换需要真实路径。想放到桌面时放「双击运行」的链接，不要复制。服务日志写在同目录的 `doc2kb_web.log`（该目录不可写时写到 `~/.cache/doc2kb/`）。

### 命令行增量模式（定时任务）

```bash
# 第一次：建立水位，先拉最近 30 天
./doc2kb.sh -s 源目录 -o 输出目录 -d 30

# 以后每次：裸跑，只出上次之后的新变更
./doc2kb.sh -s 源目录 -o 输出目录
```

crontab 示例（每天 18:30 跑一次，路径一律写绝对路径；需要中文时在命令前加 `DOC2KB_LANG=zh`）：

```
30 18 * * * DOC2KB_LANG=zh /home/user/tools/doc2kb.sh -s /home/user/文档 -o /home/user/tools/output/wd >> /home/user/tools/output/wd/cron.out 2>&1
```

常用选项（每个长选项都有等价单字母短选项，手工敲命令建议用短选项）：

| 选项 | 作用 |
| --- | --- |
| `-d N` | 处理最近 N 天内修改的文档（窗口模式） |
| `-t DATE` | 指定起点，`YYYY-MM-DD` 或 `"YYYY-MM-DD HH:MM"` |
| `-i` / `-I` | 导出 / 不导出图片（默认不导，只要文字，速度快） |
| `-E` | 不把嵌入的 Excel 展开进正文 |
| `-x 后缀` | 输出文件名后缀（中文默认「增量」） |
| `-n` | 只报告会处理哪些文件，不实际生成（dry-run） |
| `-h` | 显示帮助 |

退出码：0 正常（含无新增），1 参数或环境错误，2 处理失败，3 首次运行未指定时间范围。

### 直接调用转换器

```bash
python3 doc2kb_core.py --batch 源目录 -o 输出目录 --merge --lang zh   # 批量，合并成单个 md
python3 doc2kb_core.py --files 清单.txt -o 输出目录 --lang zh          # 处理清单中列出的文件
python3 doc2kb_core.py -h                                              # 查看全部参数
```

其他工具可以导入 `doc2kb_core.py`，通过 `build_parser()` 和 `run_batch()` / `run_files()` 的 `writer` 参数写出自己的产物；接口见 SPEC.md 第 5.6 节。

批量运行除了给人看的汇总，还输出 `STAT<TAB>键<TAB>值` 行（new、kept、failed、written、dup、moved、chars、images）和 `FAILED<TAB>路径` 行，供脚本读取。

### 清理重复内容（目录移动后的大增量文件）

子目录被移动、改名或整批复制后，增量模式会把这些文件当作新变动；正文已入库的会被输出目录里的正文指纹库 `.doc2kb_watch_fp` 识别，只列出路径对照。指纹库建立之前已经生成的大增量文件，用 `doc2kb_dedup.py` 清理：

```bash
# 1. 先试运行，只出报告（目标_去重报告.txt），不改文件
python3 doc2kb_dedup.py 输出目录/文档_20261007_增量.md -n

# 2. 核对报告无误后正式运行：原文件自动备份为 .bak-时间，
#    同时建立正文指纹库 .doc2kb_watch_fp，以后增量运行自动跳过已入库内容
python3 doc2kb_dedup.py 输出目录/文档_20261007_增量.md
```

- 默认以目标同目录的其他 md（历史增量文件、全量合并文件、独立模式产物）为比对基准，也可用 `-b 文件或目录` 多次指定。
- 只删除正文文字完全相同的节（忽略元信息、标题层级、图片路径与空白差异）；搬移前后改过内容的文档会保留。
- 删除的节在索引区「内容未变、仅位置变动的文档」表中列出现路径、原路径和正文所在文件。
- 不动源文档，不删图片；被删节引用过的图片目录列在报告里，需要时手动清理。
- 若该文件已导入知识库，清理后需在知识库端用新文件替换旧文件。

## 格式与行为

- 支持格式：`.docx` / `.xlsx` / `.xlsm` / `.pptx` / `.pdf` / `.eml`，以及 Office 97 及以后的旧版二进制 `.doc` / `.xls` / `.ppt`（取文字和表格，不导出图片；有密码保护的和更早版本的列为失败）。
- `.msg` 不支持：遇到时不崩溃，归入「需先转格式」清单。
- 压缩包：`.zip`、`.tar`、`.tar.gz`/`.tgz`、`.tar.bz2`/`.tbz2`、`.tar.xz`/`.txz` 按目录读取，包内文档在扫描清单、索引和报告里写作 `包.zip/a/报告.docx`，可用于 `--only` 与增量任务；也可直接指定压缩包（`python3 doc2kb_core.py 包.zip`）。包中包最多展开 3 层。包内文件只解到私有临时目录，运行结束即删除，不在压缩包旁写任何文件，包内路径也不会越出该目录。加密的文件、解压后超过 512 MB 的文件、单个压缩包内文档合计超过 2 GB、损坏的压缩包，以及 `.7z`/`.rar`（标准库无法读取）都列为失败并写明原因。中文 Windows 打包、未标 UTF-8 的 zip 文件名按 GBK 还原。
- 去重（同一次运行内）：先比字节（SHA-256，压缩包内文件同样计算），字节完全相同的只解析一份，保留顺序为已有产物的一份、压缩包外的一份、路径排序第一的一份；解析后再比正文，正文相同的只保留文档时间最新的一份。两类重复都列在报告「重复文件」一节，并在保留那份的开头注明其他副本位置。`-D` 保留全部副本。跨运行的去重见上文增量模式的正文指纹库。
- 产物默认合并模式（索引 + 全部正文写进单个 Markdown），另有独立模式（每份文档一个 md）。
- 增量模式以「上次成功运行时刻」为水位，任何一次成功运行都会推进水位；变动判定取文件系统修改时间、状态变更时间与文档内部属性时间三者中最晚者，新拷入的旧文件也能捕获。
